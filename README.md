# detalkipro-core-docs

Официальная документация ядра экосистемы DetalkiPro.

## Структура

- `architecture/` — архитектура системы, диаграммы взаимодействия модулей.
- `blockchain/` — описание detalkipro-chain: транзакции, хеширование, валидация.
- `webasyst-integration/` — интеграция с WebAsyst (без раскрытия секретов).
- `api/` — API-спецификации, JSON-схемы, коды ошибок.
- `deployment/` — инструкции по деплою, Docker, переменные окружения.
- `grants/` — материалы для грантовых заявок: уникальность, инновации, сертифицированная среда.

## Статус

В активной разработке. Актуальная версия — ветка `main`.
