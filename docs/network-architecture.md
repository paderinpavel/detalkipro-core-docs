# Архитектура сети CORE («ДеталькиПро»)

Сеть строится по схеме: **1 генезис‑нода + 10–20 рабочих нод** в разных регионах (Москва, Санкт‑Петербург, Хабаровск, Амурская область).

## Роли нод

- **Генезис (seed):** единственная нода, которая изначально создаёт цепочку. На данный момент это нода с IP `185.130.113.37`.
- **Рабочие ноды:** синхронизируются с генезисом, участвуют в валидации транзакций и поддержании консенсуса.

## Как подключаются рабочие ноды

Каждая новая нода при старте обращается к seed‑адресу:

- API: `http://185.130.113.37:9047`
- P2P: `185.130.113.37:9046`

После этого она скачивает блокчейн и начинает синхронизацию.

## Масштабирование

План: развернуть сеть из 10–20 нод до Нового года для выхода токена CORE на биржу.
