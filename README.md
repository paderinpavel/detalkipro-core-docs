# detalkipro-core-docs

Документация по ядру экосистемы DetalkiPro (detalkipro-chain, dpi-core, интеграция с WebAsyst).

## Структура

- `architecture/` — архитектура системы, схемы взаимодействия компонентов.
- `blockchain/` — описание блокчейна detalkipro-chain, форматы транзакций, хеширование.
- `webasyst-integration/` — инструкции по интеграции с WebAsyst, вебхуки, формат событий.
- `api/` — описание API сервисов, примеры запросов/ответов.
- `deployment/` — инструкции по деплою, Docker, переменные окружения.
- `grants/` — материалы для грантовых заявок (описание инноваций, уникальность, сертифицированная среда).

## Статус

В активной разработке. Актуальная версия документации — в ветке `main`.

## Как вносить правки

1. Создайте ветку: `git checkout -b feature/docs-<тема>`
2. Обновите нужные файлы в Markdown.
3. Сделайте PR в `main`.
4. При необходимости обновите оглавление в `README.md`.
