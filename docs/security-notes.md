# Security Notes — «ДеталькиПро» CORE Network

## Что нельзя выкладывать в репозиторий

- Папка `data` (история блокчейна, приватные ключи).
- Любые приватные ключи и токены.
- SSH‑ключи.
- Логи с чувствительной информацией.

## Что можно и нужно выкладывать

- Публичные IP и порты.
- Инструкции по установке и настройке.
- Примеры конфигов без секретов.
- Скрипты проверки статуса.

## Риски

- Сброс папки `data` на генезис‑ноде = потеря всей истории сети.
- Копирование `data` между нодами = рассинхронизация и конфликты.
