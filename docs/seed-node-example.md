# Паспорт генезис‑ноды сети CORE («ДеталькиПро») — шаблон для 
развёртывания

Этот документ — пример конфигурации для поднятия тестовой или партнёрской 
ноды. Реальные IP‑адреса, порты и пути к данным не публикуются в целях 
безопасности.

## Контакты сети (seed) — пример значений

IP‑адрес узла: `<SEED_HOST>` *(замените на адрес вашей ноды)*  
Порт API: `<API_PORT>` *(пример: 8080)*  
Порт P2P: `<P2P_PORT>` *(пример: 8081)*

## Статус (пример вывода)

Статус сервиса: `active (running)`  
PID процесса: `<PROCESS_ID>` *(не публикуется)*  
Папка данных: `~/detalkipro/data` *(уникальна для каждого узла; не 
копируйте между нодами)*

## Для подключения других нод — формат строки

Seed URL для конфигурации: `http://<SEED_HOST>:<API_PORT>`  
P2P‑адрес для пиров: `<SEED_HOST>:<P2P_PORT>`

⚠️ **Важно:** В этом документе приведены только примеры и структура. 
Реальные адреса и доступы к PROD‑ноде выдаются отдельно по запросу для 
партнёров и участников сети.
